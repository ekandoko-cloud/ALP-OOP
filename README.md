## SpaceGame (window kecil, tanpa Enter)

`src/minigames/SpaceGame.java` sekarang memakai window Swing kecil supaya pemain bisa menekan `SPACE` langsung tanpa perlu `ENTER`.

### Run
```powershell
Set-Location "D:\KULIAH\SEMESTER 2\ADVANCED PROGRAMMING\ALP OOP PT2"
$cp = "src"
javac -encoding UTF8 -cp $cp -sourcepath src -d out src\main\App.java
java -cp "out" main.App
```

### Catatan
- Game ini muncul di **window kecil**.
- Tekan `SPACE` langsung, **tanpa `ENTER`**.

### Cara main
1. Buka menu mini game
2. Pilih `Spasi Game`
3. Klik window kecilnya
4. Tekan `SPACE` selama 10 detik
