## 🔄 Data Flow Diagram

### Inventory System Flow
```
User Input
    │
    ▼
┌─────────────────────────────────┐
│ Check Action                    │
├─────────────────────────────────┤
│ Display │ Search │ Detail       │
│ Use     │ Add    │ Remove       │
└─────────────────────────────────┘
    │       │         │
    ▼       ▼         ▼
Sorted    Search     Display
A-Z       Results    Info
    │       │         │
    └───────┴─────────┘
            │
            ▼
    Display to User
```

### Shop System Flow
```
User: "Buy Item"
    │
    ▼
┌─────────────────────────────────┐
│ [1] Item Available?             │ ─→ NO ─→ Fail: Item Not Found
├─────────────────────────────────┤
│ [2] Gold Sufficient?            │ ─→ NO ─→ Fail: Insufficient Gold
├─────────────────────────────────┤
│ [3] Inventory Slot Free?        │ ─→ NO ─→ Fail: Inventory Full
├─────────────────────────────────┤
│ [4] All Pass?                   │ ─→ YES ─→ Process Transaction
├─────────────────────────────────┤
│ - Reduce Gold                   │
│ - Add Item to Inventory         │
│ - Display Success Message       │
└─────────────────────────────────┘
```

### Crafting System Flow
```
User: "Craft Potion"
    │
    ▼
┌─────────────────────────────────┐
│ [1] Recipe Exists?              │ ─→ NO ─→ Fail: No Recipe
├─────────────────────────────────┤
│ [2] All Ingredients Available?  │
│    (Check quantity)             │
│                                 │ ─→ SOME MISSING ─→ Fail: List Missing
├─────────────────────────────────┤
│ [3] Reduce Ingredients          │
├─────────────────────────────────┤
│ [4] Roll Success Rate           │ ─→ NO ─→ Fail: Ingredients Used
│    (Random 0-100)               │
├─────────────────────────────────┤
│ [5] Success?                    │ ─→ YES ─→ Add Result Item
└─────────────────────────────────┘
```

### Forge System Flow
```
User: "Upgrade Sword"
    │
    ▼
┌─────────────────────────────────┐
│ [1] Equipment Exists?           │ ─→ NO ─→ Fail: No Equipment
├─────────────────────────────────┤
│ [2] Level < +10?                │ ─→ NO ─→ Fail: Already Max
├─────────────────────────────────┤
│ [3] Get Next Level Formula      │
├─────────────────────────────────┤
│ [4] Material Sufficient?        │ ─→ NO ─→ Fail: Material Lacking
├─────────────────────────────────┤
│ [5] Reduce Material             │
├─────────────────────────────────┤
│ [6] Increase Level & Stats      │
│    (Using Formula)              │
├─────────────────────────────────┤
│ [7] Display Success Message     │
└─────────────────────────────────┘
```

## 💾 Data Structure Usage

### InventorySystem
```
LinkedList<Item>
┌─────┐     ┌──────┐     ┌─────────┐     ┌──────┐
│Node │◄───►│ Item │◄───►│  Node   │◄───►│Item  │
└─────┘     │      │     │         │     │      │
            └──────┘     └─────────┘     └──────┘
(Double Linked List - good for sorting & traversal)
```

### ShopSystem
```
ArrayList<Item>
┌───┬───┬───┬───┬───┬─────┐
│ 0 │ 1 │ 2 │ 3 │ 4 │ ... │
├─────────────────────────┤
│Item│Item│Item│Item │...  │
└───┴───┴───┴───┴───┴─────┘

## 🎮 Game Flow Integration

```
MAIN MENU
    │
    ├─→ [1] EXPLORE
    │        │
    │        ├─→ Encounter Monster ─→ Battle ─→ Get Loot
    │        │
    │        └─→ Find Treasure ─→ Add to Inventory
    │
    ├─→ [2] INVENTORY ◄─── (InventorySystem)
    │        │
    │        ├─→ View Items (Sorted A-Z)
    │        ├─→ Search Item
    │        ├─→ Use Consumable
    │        └─→ View Details
    │
    ├─→ [3] SHOP ◄─── (ShopSystem)
    │        │
    │        ├─→ View Items
    │        ├─→ Buy Item
    │        │   └─→ Gold Check ✓
    │        │   └─→ Slot Check ✓
    │        │   └─→ Add to Inventory
    │        └─→ View Details
    │
    ├─→ [4] CRAFT ◄─── (CraftingSystem)
    │        │
    │        ├─→ View Recipes
    │        ├─→ Select Recipe
    │        │   └─→ Check Ingredients ✓
    │        │   └─→ Roll Success Rate
    │        │   └─→ Add to Inventory
    │        └─→ View Details
    │
    └─→ [5] FORGE ◄─── (ForgeSystem)
             │
             ├─→ View Equipment
             ├─→ Select Equipment
             │   └─→ Check Level < +10 ✓
             │   └─→ Check Material ✓
             │   └─→ Upgrade (Level + Stats)
             └─→ View Upgrade Chart
```

## 📊 Algorithm Complexity Summary

| System | Operation | Algorithm | Complexity |
|--------|-----------|-----------|-----------|
| Inventory | Sort A-Z | Bubble Sort | O(n²) |
| Inventory | Search | Linear Search | O(n) |
| Shop | Buy | Validation Chain | O(n) |
| Crafting | Validate | Material Check | O(k·n) |
| Forge | Upgrade | Stat Calc | O(1) |

Legend: n = inventory size, k = number of ingredients

    │ YES               └────────────────┘
    ▼
┌─────────────────┐
│ Execute Action  │
└─────────────────┘
    │
    ▼
Update State & Return Success
```
